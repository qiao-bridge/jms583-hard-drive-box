# jms583硬盘盒

#### 介绍
解决存储大容量与读取速度问题，采用硬盘盒+M.2固态的组合形式，可以达到400MBps。嘉立创开源地址：https://oshwhub.com/qiao_wen/jms583-based-hard-disk-box
